Quick start — OLM install

# 1. Add the catalog
oc apply -f - <<EOF
apiVersion: operators.coreos.com/v1alpha1
kind: CatalogSource
metadata:
  name: pulse-operator-catalog
  namespace: openshift-marketplace
spec:
  sourceType: grpc
  image: quay.io/amobrem/pulse-operator-catalog:latest
  displayName: Pulse Operator
  publisher: Red Hat CoE
EOF

# 2. Create namespace + secrets
oc new-project openshiftpulse
oc create secret generic gcp-sa-key \
  --from-file=key.json=./sa-key.json -n openshiftpulse

# 3. Subscribe
oc apply -f - <<EOF
apiVersion: operators.coreos.com/v1alpha1
kind: Subscription
metadata:
  name: pulse-operator
  namespace: openshiftpulse
spec:
  channel: alpha
  name: pulse-operator
  source: pulse-operator-catalog
  sourceNamespace: openshift-marketplace
EOF

# 4. Deploy your Pulse instance
oc apply -f https://raw.githubusercontent.com/PulseSRE/pulse-operator/main/examples/pulse.yaml

Everything managed, nothing forgotten

🤖

AI SRE Agent

Claude-powered agent with configurable trust levels from read-only observation to autonomous remediation.

🔐

OpenShift OAuth

oauth-proxy sidecar auto-configured with OAuthClient, redirect URIs detected from the live Route.

🗄️

PostgreSQL included

UBI PostgreSQL StatefulSet with pg-data PVC retained on CR delete — data survives operator upgrades.

📊

Monitoring built-in

ServiceMonitor and PrometheusRule alerts ship out of the box with monitoring.enabled: true.

🔌

MCP tool extension

Optional MCP server sidecar lets you extend the agent with custom tools and data sources.

🌐

ACM multicluster

Auto-detects ACM availability and enables multicluster visibility when the hub is present.

🛡️

Security-first

All pods run non-root with AllowPrivilegeEscalation=false, Capabilities.Drop=ALL, and seccomp RuntimeDefault.

♻️

Clean uninstall

Finalizer removes cluster-scoped resources (ClusterRoles, OAuthClient) when the CR is deleted. No orphans.

How it works

One CR, one operator, the full stack.

1

Apply an OpenShiftPulse CR

Set your AI backend secret, trust level, and image tags. Everything else is auto-detected.

2

Operator reconciles all sub-resources

Agent, PostgreSQL, UI, OAuthClient, Route, ServiceMonitor — in dependency order.

3

Route becomes available

OCP router assigns the hostname. Operator patches the OAuthClient redirect URI automatically.

4

Authenticate and start using Pulse

OpenShift OAuth handles login. Ask the agent about your cluster in plain English.
