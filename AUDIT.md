# Pulse Operator — Reliability Audit

Generated by Claude Code audit agent. Ranked by severity.

---

## BLOCKERS

### Dual reconcile path — race condition
`agent_reconciler.go:103` + `openshiftpulse_controller.go:183`

`AgentReconciler.SetupWithManager` registers it as an independent controller AND `OpenShiftPulseReconciler.reconcileAgent` calls its steps directly. Every watch event fires two concurrent reconcile paths against the same CR. Remove the `SetupWithManager` call and drive everything from the root reconciler, or remove the direct call from the root reconciler.

## HIGH

### Cluster info cache never retries on partial failure
`cluster_detect.go:43` — `clusterInfoOnce` caches forever even if ImageStream GET errored but Ingress GET succeeded. Wrong `OAuthProxyImage` is stuck for the process lifetime. Add a retry flag or cache expiry.

### `reconcilePGService` is create-only — drift not corrected
`postgresql_reconciler.go:249–291` — Service selector/port drift is never corrected. Switch to `CreateOrUpdate`.

### `databaseEnabled()` is always true
`agent_reconciler.go:135` — `StorageSize` has `+kubebuilder:default="5Gi"` so database is always enabled. No opt-out path. Document or remove the condition.

### Status update skipped when Route is pending
`openshiftpulse_controller.go:101–109` — Early return skips `r.Status().Update()`. Status conditions go stale until Route is admitted.

### No "Degraded" phase
`openshiftpulse_controller.go:120–132` — Phase never reaches `"Degraded"`. If agent crashes after first being healthy it oscillates between Installing/Running. Add Degraded with condition details.

### `status.agentVersion` never written
`types.go:107` — Field and printcolumn exist but no reconciler reads the agent image tag and sets it.

### Finalizer stops on first error — leaves orphans
`openshiftpulse_controller.go:152–196` — If ClusterRole delete fails, all remaining cleanup is skipped. Attempt all deletions, aggregate errors.

### MCP server has no readiness probe
`mcp_reconciler.go:100–108` — Service selects the pod immediately; traffic hits it before the MCP server is ready. Add an HTTP readiness probe on `GET /healthz`.

### Operator ClusterRole grants cluster-wide secret write
`deploy/operator.yaml:21` — `secrets` with `create;patch;update` is cluster-scoped. Scope it to managed namespaces via RoleBindings instead.

### Agent ClusterRole includes `services/proxy`
`agent_reconciler.go:186` — Allows HTTP proxying to any service in any namespace. Remove — not needed for read-only SRE.

### PostgreSQL pod has no resource requests/limits
`postgresql_reconciler.go:195–235` — Unbounded. Can OOMKill silently. Add reasonable defaults (256Mi request, 1Gi limit).

### MCP server pod has no resource requests/limits
`mcp_reconciler.go:87` — Same issue.

### No Kubernetes Events emitted anywhere
No `record.EventRecorder` in any reconciler. `kubectl describe openshiftpulse` shows nothing. Users have no audit trail. Add events for: CR created, route admitted, component degraded, upgrade completed.

### Test coverage missing for entire reconcilers
No tests at all for: `PostgreSQLReconciler`, `MonitoringReconciler`, `MCPReconciler`, `NetworkPolicyReconciler`, `PDBReconciler`, finalizer/deletion path, `ClusterDetector`.

Agent reconciler tests missing: AI credential injection, `AllowWriteOperations`/`AllowSecretAccess` RBAC expansion, MCP URL injection, full CR lifecycle (create → all resources exist → delete → all cleaned up).

## MEDIUM

### MCPReconciler full spec replace on update
`mcp_reconciler.go:128` — `existing.Spec = desired.Spec` clobbers any manual scaling or resource edits. Switch to `CreateOrUpdate`.

### `{name}-postgresql` connection secret has no owner ref
`postgresql_reconciler.go:72–86` — Created without `SetControllerReference`. Won't be garbage-collected when CR is deleted.

### No per-component status conditions
Single `Ready` condition is not enough. Add `AgentReady`, `DatabaseReady`, `UIReady` conditions so alerts and tooling can distinguish failures.

### No timeout/max-retry on stuck finalizer
Stuck OAuthClient delete hangs the CR terminating indefinitely. Add a configurable timeout with a force-complete escape hatch.

### StatefulSet UpdateStrategy `Partition` not set
`postgresql_reconciler.go:157` — Fine for now but no pre-upgrade quiesce step.

### WS token secret never rotated
`agent_reconciler.go:278` — No rotation mechanism. Leaked token requires manual secret deletion.

### oauth-proxy cookie secret never rotated
`ui_reconciler.go:183` — Same. Compromised cookie secret can't be revoked without manual intervention.

### AgentReconciler kubebuilder marker over-grants
`agent_reconciler.go:44` — Claims `create;update;patch;delete` on `openshiftpulses` but only reads the CR. Change to `get;list;watch`.

### Agent and UI have no default resource limits
Empty `Resources` in spec defaults to unbounded. Add recommended defaults in the CRD or reconciler.

### No custom controller metrics
No metrics for: managed resource health, number of active CRs, time-to-ready. Only default controller-runtime metrics.

## LOW

### PostgreSQL liveness probe missing `-h localhost`
`pg_isready -U pulse` without `-h` may fail in some network configurations.

### Log level usage inconsistent
No convention for what belongs at `V(1)` vs `Info`. Verbose paths mixed with lifecycle events.

### PostgreSQL password never rotated
By design, but no operator-side rotation command exists.
